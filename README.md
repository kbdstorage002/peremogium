# Перемогіум

Велика картина війни в цифрах. Сторінка для тих моментів, коли окрема новина вибиває з колії.

## Сторінки

- `index.html` — головна: чотири головні цифри, «Цифра дня» (щодня інша, з тих самих даних), вітрини розділів з міні-графіками (анімуються, коли потрапляють в поле зору), блок «Чесно».
- `year.html` — рік проти попереднього (`year.html?y=2026`). Старі посилання `./?y=…` головна перенаправляє сюди.
- `war.html` — поточний рік проти всієї війни.
- `calendar.html` — календар втрат.
- `npz.html` — «НПЗдець», удари по НПЗ рф.
- `recruit.html` — «срекрутинг»: вербування в армію рф, бонуси, виплати, набір проти втрат.

## Як оновлюються дані

- **Автоматично, щодня** (GitHub Actions, `.github/workflows/update-data.yml`). Скрипт `scripts/update-data.mjs` бере:
  - втрати рф із щоденних зведень Генштабу ЗСУ (архів russianwarship.rip);
  - окуповану площу зі знімків карти DeepState на 1-ше число кожного місяця.
- **Вручну, раз на місяць**: нафтогазові доходи рф у `data/manual.json`, після публікації Мінфіну рф (зазвичай 3–5 числа).
- **Удари по НПЗ** (сторінка «НПЗдець»): щодня скрипт `scripts/update-npz.mjs` (`npm run update:npz`) дочитує нові удари з переліку атак БпЛА у Вікіпедії й додає їх у `data/npz.js`. Нічого не видаляє, тож вручну можна виправити чи додати рядок у `strikes`. Якщо в лозі Actions з'являються рядки «?» — у Вікіпедії згадано завод, якого немає в довіднику: додайте його в `refineries` (з полем `match`). Перше наповнення 2022–2025 зібране скриптами з `scripts/npz/`.

- **Вербування** (сторінка «срекрутинг»): вручну в `data/recruit.js`, коли виходить нова оцінка Клюге (janiskluge.substack.com) чи «Важных историй» (приблизно раз на місяць-квартал). Втрати й територію сторінка бере з `data/data.js` сама, за той самий період, що й оцінка набору (`kluge.months`). На початку нового року — перевести `cur`/`prev` і ключі `y2026`/`y2025`.

## Новий рік

Роки беруться з дати, тож 1 січня все перемикається само: скрипт починає збирати дані за новий рік,
у меню з'являється вкладка «2027 проти 2026» (`year.html`), а «2026 проти 2025» лишається поруч (`year.html?y=2026`).
Поки за новий рік немає жодного дня даних, `year.html` і головна показують попередню пару. Кольори років — у `assets/years.js`.

Вручну на початку року: коли Мінфін рф опублікує підсумок року, перенести повне значення в
`data/manual.json` → `oilGasYears.years`, а `oilGas` перевести на новий рік (`year`, `period`, `value`, `changePct`).

## Локально

```bash
npm install
npm run update               # оновити data/data.json і data/data.js
node scripts/serve.mjs 8765  # переглянути на http://127.0.0.1:8765
```
