# Перемогіум

Велика картина війни в цифрах: 2025 проти 2026. Сторінка для тих моментів, коли окрема новина вибиває з колії.

## Як оновлюються дані

- **Автоматично, щодня** (GitHub Actions, `.github/workflows/update-data.yml`). Скрипт `scripts/update-data.mjs` бере:
  - втрати рф із щоденних зведень Генштабу ЗСУ (архів russianwarship.rip);
  - окуповану площу зі знімків карти DeepState на 1-ше число кожного місяця.
- **Вручну, раз на місяць**: нафтогазові доходи рф у `data/manual.json`, після публікації Мінфіну рф (зазвичай 3–5 числа).
- **Удари по НПЗ** (сторінка «НПЗдець»): щодня скрипт `scripts/update-npz.mjs` (`npm run update:npz`) дочитує нові удари з переліку атак БпЛА у Вікіпедії й додає їх у `data/npz.js`. Нічого не видаляє, тож вручну можна виправити чи додати рядок у `strikes`. Якщо в лозі Actions з'являються рядки «?» — у Вікіпедії згадано завод, якого немає в довіднику: додайте його в `refineries` (з полем `match`). Перше наповнення 2022–2025 зібране скриптами з `scripts/npz/`.

## Локально

```bash
npm install
npm run update               # оновити data/data.json і data/data.js
node scripts/serve.mjs 8765  # переглянути на http://127.0.0.1:8765
```
