## Хостинг: зміна сервера ламає заливку

*Записано 17.11.2026*

> Якщо uahosting перенесе вас на інший сервер (наприклад, s7 замість s6), заливка впаде з тією самою помилкою сертифіката. Тоді в DEPLOY_HOST треба буде вписати нову назву сервера.

**Як упізнати:** приходить лист від GitHub про невдалий запуск «Оновлення даних і публікація». У лозі кроку «Залити на хостинг» є рядок `certificate common name doesn't match requested host name`.

**Як знайти нову назву сервера:** у панелі uahosting, в розділі FTP або «Інформація про сервер». Або попросити Claude: він визначить її за адресою `ftp.calmnessuniverse.art`.

**Де змінити:** https://github.com/kbdstorage002/peremogium/settings/secrets/actions → `DEPLOY_HOST` → Update.

**Зараз:** `s6.uahosting.com.ua` (IP 40.160.23.215). Сертифікат `*.uahosting.com.ua` дійсний до 1 травня 2027.
